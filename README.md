# 新澳门六合彩 9生肖优化版

## 最重要修复
macaujc.com API 生肖常用繁体：
馬、龍、雞、豬

前端旧版使用简体：
马、龙、鸡、猪

两者字符串不相等，会造成大量“假未中”。新版在 API 层统一转为简体后再统计。

## 10套优化公式
1. 稳健综合
2. 短线热势
3. 中线均衡
4. 长线稳定
5. 热度防断
6. 回补平衡
7. 低波动
8. 动量增强
9. 防冷过滤
10. 多模型共识

全部使用逐期滚动回测。

## 部署
把 app、package.json、next.config.js 放在 GitHub 仓库根目录，然后 Vercel Redeploy。
